# 冻结旧版行为基线

基线提交：`07919d35ba192e28570c9bf4a19a52da5dd86ff9`  
冻结版本：`1.6.19`  
冻结文件：`legacy/fanxiulu-monolith.html`

## 1. 战斗

- 固定顺序为玩家行动，敌人未死亡则立即反击。
- 玩家基础会心 5%、倍率 1.6；基础闪避 4%。
- 敌人基础会心 4%、倍率 1.5；基础闪避 3%。
- 玩家会心有 10% 概率眩晕敌人并跳过一次反击。
- 遁走成功率 60%；失败承受约 70% 强度追击。
- 精英、命名强敌和区域首领沿用冻结倍率、状态和奖励规则。

## 2. 死亡

- 普通角色损失约 15% 灵石、当前升级需求约 10% 修为和 5 点声望，返回绑定区域并恢复状态。
- 生死道角色死亡会删除角色槽，并写入旧名人堂数据。
- P0 不改变生死道收益、死亡或组队限制。

## 3. 装备与背包

- 六槽固定为主法器、副手法器、衣袍、护腿、鞋履和饰品。
- 装备/卸下必须保持旧版属性合成语义。
- 物品锁定、收藏、插槽、符纹、套装、词缀和未知旧字段必须原样保留。
- 自动装备比较继续使用旧版综合属性与阈值规则。

## 4. 功法

- 每个初始传承沿用 6 本标准功法和 1 本史诗功法。
- P0 保留学习条件、费用、法力、冷却、记忆槽和自动施法规则。
- P0 不限制为三功法，也不加入回合冷却。

## 5. 挂机与离线

- 挂机继续按旧目标规划、补药、回灵、功法、攻击、调息和寻敌顺序执行。
- 普通区域、队伍和秘境离线结算使用现有独立模拟器。
- 离线摘要包含战斗、修为、灵石、掉落、符纹、声望及兼容进度。
- P0 不重做洞府，不改变离线收益倍率。

## 6. 长期系统与网络功能

- 悟道、重修/飞升、符纹、同行、护道者、灵兽、旧炼丹、神龛和套装收藏在原生 P0 中只读。
- 赌场、聊天、宗门、Discord、管理员和 LFG 在默认原生入口隐藏。
- 所有对应旧存档字段继续保留；legacy 模式仍可查看和操作。

## 7. 回归来源

- 固定规则测试：`tests/unit/` 与 `tests/regression/legacy-baseline.test.ts`。
- 冻结页面回归：`tests/e2e/legacy-bridge.spec.ts`。
- 完整机制目录：`GAME_MECHANICS_CATALOG.md`。

## 8. P0 原生验收状态

- 默认 `/` 与 `/?mode=equivalent` 已使用无 iframe 的 Vue 原生等价壳；`/?mode=legacy` 保留冻结版本。
- 原生壳继续执行本报告记录的旧战斗、装备、功法、挂机、离线和死亡规则。
- 原生界面以冻结提交 `07919d3` 为 UI/交互基准，保留旧式登录卡、角色库舞台、暗绿/金色面板、顶部工具条、桌面三栏、战斗场景、六槽装备和并排比较。
- 冻结外围系统只读或隐藏，不会后台推进；CloudBase 权威结算继续延期。
- P0 单元/回归、生产构建、冻结基线、桌面与移动 E2E 均作为进入 P1 前的强制门禁。
